# Ejemplo navegable de MS-2

Abrir MS2-demo.html con doble clic para usar el ejemplo autocontenido. Alternativamente abrir index.html conservando las carpetas; no se usan fuentes ni librerías externas.

El selector superior permite revisar las escenas 1, 2, 11 y 12 del Nivel 3 y los estados docentes. COMENZAR, respuestas, ELEGIR, CONTINUAR, AYUDA, SEÑAS y ajustes son interactivos. Usar Tab, flechas en radios, Espacio para casillas y Escape para cerrar los diálogos.

Los controles LSEC muestran un video pendiente hasta disponer de una grabación aprobada. Para integrar un clip en la versión de varios archivos: copiarlo a assets/lsec/, agregar su ID en SIGN_CLIPS (data.js) con src local y status: validado, después de registrar aprobación en el catálogo. No marcar validado para ocultar el estado de pendiente.

La voz del sistema es una demostración condicionada al navegador; no acredita disponibilidad offline. Las preferencias se guardan localmente cuando el navegador lo permite. No hay datos de estudiantes ni conexión con el progreso real del juego.
